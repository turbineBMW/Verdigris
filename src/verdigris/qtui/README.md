# Verdigris legacy Qt frontend

This optional frontend uses the Verdigris Bluetooth backend. Start the daemon with
`verdigris run`, check setup with `verdigris doctor`, and open `verdigris-qt`.

The primary Verdigris desktop apps are `verdigris-messages` and `verdigris-phone`.
Verdigris is a fork of [Blue](https://github.com/gutbash/blue).
